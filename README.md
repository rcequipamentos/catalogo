# RC Equipamentos · Catálogo

- `index.html` — catálogo para clientes (monta orçamento, gera PDF e envia pelo WhatsApp)
- `admin.html` — gestão: preços pelo dólar, preço individual, novos produtos, editar, ocultar e remover
- `data/produtos.json` — produtos e preços de venda (gerado pela gestão; não editar à mão)
- `fotos/` — fotos dos produtos (`fotos/p/` = fotos enviadas pela gestão)

Custos em dólar ficam no repositório privado `rc-custos` (arquivo `custos.json`).
